# Rob's Aquatics - Spec Website Rebuild

Modern one-page rebuild of Rob's Aquatics (Tinley Park, IL), based on archived site structure/content and refreshed for a clean, professional presentation.

## Included in this build

- Responsive, modern one-page layout
- Legacy navigation choices preserved:
  - Home
  - About
  - Aquarium Installment
  - Services
  - Imagery
  - Testimonials
  - 360 Tour
  - Contact
- Authentic Rob's Aquatics logo placed in the upper-left
- Updated service copy and contact section
- Embedded 360 tour and map
- Mobile navigation + image modal interactions
